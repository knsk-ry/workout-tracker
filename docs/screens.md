# 画面構成

- ダッシュボード
- トレーニングメニュー
- 記録

## ダッシュボード

### 目的

今日行うメニューを確認し、トレーニング、ストレッチ、睡眠、食事を少ない操作で記録する。

### 表示項目

- 今日のトレーニングメニュー
- 今日のストレッチメニュー
- トレーニング・ストレッチの完了チェック
- 入眠時刻
- 起床時刻
- 朝食
- 昼食
- 夕食
- メモ
- 今日の記録を保存するボタン
- 今月のトレーニング回数
- 最近の記録
- 記録ページへのリンク

### レイアウト

```
html
  ├ header
  │  ├ a logo
  │  └ nav
  │    └ ul
  │      ├ li a ダッシュボード
  │      ├ li a トレーニングメニュー
  │      └ li a 記録
  │
  ├ main
  │  ├ section 今日のメニュー
  │  │ ├ h2 今日のメニュー
  │  │ ├ fieldset トレーニング
  │  │ │ └ label
  │  │ │   └ input type="checkbox"
  │  │ └ fieldset ストレッチ
  │  │   └ label
  │  │     └ input type="checkbox"
  │  │
  │  ├ section 生活記録
  │  │ ├ h2 生活記録
  │  │ ├ label 入眠時刻
  │  │ │ └ input type="datetime-local"
  │  │ ├ label 起床時刻
  │  │ │ └ input type="datetime-local"
  │  │ ├ label 朝食
  │  │ │ └ textarea
  │  │ ├ label 昼食
  │  │ │ └ textarea
  │  │ ├ label 夕食
  │  │ │ └ textarea
  │  │ ├ label メモ
  │  │ │ └ textarea
  │  │ └ button 今日の記録を保存
  │  │
  │  ├ section 今月のトレーニング回数
  │  └ section 最近の記録
  │
  └ footer
```

### 操作

- メニューのチェックボックスで実施有無を入力する
- 入眠時刻と起床時刻を入力する
- 朝食、昼食、夕食、メモを入力する
- 保存ボタンを押して、その日のDaily Recordを保存する
- 同日の記録がすでに存在する場合は、既存レコードを更新する
- 保存成功時は完了メッセージを表示する
- 保存失敗時は入力内容を維持したままエラーを表示する

### 遷移先

- トレーニングメニュー
- 記録

## トレーニングメニュー

### 目的

実施しているトレーニングの内容を一覧化

### 表示項目

- トレーニング・ストレッチメニューの一覧
- メニュー名
- カテゴリ
- 予定セット数
- 予定回数
- 実施予定曜日
- 有効状態
- 表示順
- メモ
- 新規メニューの追加
- 既存メニューの編集

### レイアウト

```
form メニュー入力
├─ input メニュー名
├─ select カテゴリ
├─ input 予定セット数
├─ input 予定回数
├─ fieldset 実施予定曜日
│  ├─ checkbox 月
│  ├─ checkbox 火
│  ├─ checkbox 水
│  ├─ checkbox 木
│  ├─ checkbox 金
│  ├─ checkbox 土
│  └─ checkbox 日
├─ checkbox 有効状態
├─ input 表示順
├─ textarea メモ
└─ button 保存
```

### 操作

- 追加ボタンを押下で入力フォームがアコーディオンで表示
- 各トレーニングアイテムを押下することでトレーニング内容を表示
- 各トレーニングアイテムの右端にある編集ボタンを押下でアコーディオンでトレーニング内容を編集できる

### 遷移先

- ダッシュボード
- 記録

## 記録

### 目的

カレンダー形式でトレーニングを実施した日、内容を確認

### 表示項目

- 日別に実施したトレーニングの確認
- 食事内容の確認
- 睡眠時間の確認
- ストレッチ内容の確認

### レイアウト

```
dialog 日別記録
├─ h2 記録日
├─ section 実施したトレーニング
├─ section 実施したストレッチ
├─ section 睡眠
│  ├─ 入眠時刻
│  ├─ 起床時刻
│  └─ 算出した睡眠時間
├─ section 食事
│  ├─ 朝食
│  ├─ 昼食
│  └─ 夕食
├─ section メモ
└─ button 閉じる
```

### 操作

- 月間表示と週間表示を切り替える
- 日付を押すと、その日の記録をモーダルで表示する
- 記録画面ではデータを編集しない
- 記録が存在しない日付では「記録はありません」と表示する

### 遷移先

- ダッシュボード
- トレーニングメニュー
