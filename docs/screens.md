# 画面構成

- ダッシュボード
- トレーニングメニュー
- 記録

## ダッシュボード

### 目的

今日やることを一目で確認する

### 表示項目

- 今日のメニュー
- 今日の記録ボタン
- 今月のトレーニング回数
- 最近の記録

### レイアウト

```
Header

↓

今日のメニュー

↓

記録ボタン

↓

今月の回数

↓

最近の記録

↓

記録ページに遷移するボタン

↓

footer
```

### 操作

- 今日のメニューの横にチェックボックスがあり、チェックを言えれた後に記録ボタンを押下することでデータベースにデータが格納される

### 遷移先

- トレーニングメニュー
- 記録

## トレーニングメニュー

### 目的

実施しているトレーニングの内容を一覧化

### 表示項目

- トレーニング一覧
- 新規トレーニングの追加
- 既存トレーニングの編集

### レイアウト

```
Header

↓

追加ボタン

↓

追加用の入力フォーム（基本は非表示）

↓

トレーニング一覧のリスト
└ トレーニングアイテムには編集ボタンあり

↓

footer
```

### 操作

- 追加ボタンを押下で入力フォームがアコーディオンで表示
- 各トレーニングアイテムを押下することでトレーニング内容を表示
- 各トレーニングアイテムの右端にある編集ボタンを押下でアコーディオンでトレーニング内容を編集できる

### 遷移先

- ダッシュボード
- 記録

## 記録

### 目的

カレンダー形式でトレーニングを実施した日、内容を確認

### 表示項目

- 日別に実施したトレーニングの確認
- 食事内容の確認
- 睡眠時間の確認
- ストレッチ内容の確認

### レイアウト

```
Header

↓

カレンダー

↓

footer
```

### 操作

- 日付を押下し、モーダルでその日に対応した内容を確認

### 遷移先

- ダッシュボード
- トレーニングメニュー
