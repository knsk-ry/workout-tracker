# ワイヤーフレーム

## ダッシュボード

### ユーザーに達成してほしいこと／期待するアクション

下記内容をユーザーに確認・入力を行うようにする

- 当日行うトレーニングの確認・入力（達成した場合にチェックを入れる）
- 当日行うストレッチの確認・入力（達成した場合にチェックを入れる）
- 当日の睡眠時間の入力（入眠・起床時間）

### レイアウト（テキストベース）

```
html
  ├ header
  │  ├ a logo
  │  └ nav
  │    └ ul
  │      └ li a ダッシュボード
  │      └ li a トレーニングメニュー
  │      └ li a 記録
  │
  ├ main
  │  ├ h2 今日のメニュー
  │  │ ├ h3 当日のトレーニング
  │  │ ├ h3 当日のストレッチ
  │  │ └ h3 当日の睡眠時間
  │  │
  │  └ h2 今月のトレーニング回数
  │
  └ footer
    └ コピーライト
```

## トレーニングメニュー

### ユーザーに達成してほしいこと／期待するアクション

下記内容をユーザーに確認・入力を行うようにする

- 現在行っているトレーニング／ストレッチ内容の一覧が見れる
- トレーニング／ストレッチメニューの追加／修正ができる



### レイアウト（テキストベース）

```
html
  ├ header
  │  ├ a logo
  │  └ nav
  │    └ ul
  │      ├ li a ダッシュボード
  │      ├ li a トレーニングメニュー
  │      └ li a 記録
  │
  ├ main
  │  ├ h2 メニューの追加
  │  │ └ button メニュー追加
  │  │   └ input メニュー内容の入力
  │  │   └ button メニュー内容の登録
  │  │
  │  └ h2 メニュー一覧
  │    ├ h3 トレーニングメニュー
  │    │ └ button メニューの修正
  │    │   └ input メニュー修正内容の入力
  │    │   └ button メニュー修正内容の登録
  │    └ h3 ストレッチメニュー
  │      └ button メニューの修正
  │        └ input メニュー修正内容の入力
  │        └ button メニュー修正内容の登録
  │
  └ footer
    └ コピーライト
```



## 記録



### ユーザーに達成してほしいこと／期待するアクション

下記内容をユーザーに確認を行うようにする

- カレンダー形式でトレーニングを行った日付を確認
- 日付を押下することで行ったトレーニング／ストレッチ内容の確認、睡眠時間の確認
- 月間／週間の達成した日数の確認
- 月間／週間の平均睡眠時間を確認



### レイアウト（テキストベース）

```
html
  ├ header
  │  ├ a logo
  │  └ nav
  │    └ ul
  │      ├ li a ダッシュボード
  │      ├ li a トレーニングメニュー
  │      └ li a 記録
  │
  ├ main
  │  ├ h2 月間／週間の切り替えボタン
  │  │
  │  ├ h2 月間の記録（カレンダー）
  │  │ └ button 日付押下時にモーダルで行った内容の確認
  │  │
  │  ├ h2 月間で達成した日数
  │  │
  │  └ h2 月間平均睡眠時間
  │
  └ footer
    └ コピーライト
```
