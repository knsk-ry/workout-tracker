# UI Guidelines

## 1. Design Concept

「ゆるく継続」を表現する、落ち着きと温かみのあるデザイン。

- 操作に迷わない
- 情報を詰め込みすぎない
- 筋トレアプリらしさは残しつつ、威圧的にしない
- 毎日開いても疲れにくい

## 2. Colors

| Role | Color | Usage |
|---|---|---|
| Background | #F8F7F3 | ページ背景 |
| Surface | #FFFDF8 | カード・フォーム |
| Text Primary | #292722 | 見出し・本文 |
| Text Secondary | #6F6B63 | 補足 |
| Primary | #35785A | ボタン・チェック状態 |
| Primary Light | #E5F0E9 | 選択状態・背景 |
| Border | #DDD9D0 | 枠線 |

## 3. Typography

- 日本語フォント：システムフォント
- 見出しは太め
- 本文は通常
- 極端に細い文字は使わない

## 4. Spacing

- 基本単位：8px
- 小さい余白：8px
- 要素間：16px
- セクション間：24px〜32px

## 5. Border Radius

- ボタン：10px
- 入力欄：10px
- カード：16px
- モーダル：16px

## 6. Shadows

- 強い影は使わない
- カードは枠線を基本とする
- モーダルのみ薄い影を使用する

## 7. Buttons

### Primary

- メイン操作に使用
- 背景はグリーン
- 文字はオフホワイト

### Secondary

- 補助操作に使用
- 背景は透明
- 枠線あり

### Danger

- 削除操作に限定
- 常時目立たせない

## 8. Cards

- 関連する情報をひとまとまりにする
- カード内に操作を詰め込みすぎない
- 見出し、内容、操作の順で配置する

## 9. Forms

- ラベルは入力欄の上に表示
- 必須項目を明示する
- エラー内容を入力欄の近くに表示する
- スマホでも押しやすい高さにする

## 10. Responsive Policy

### Mobile

- 当日の記録を最優先
- 1カラム
- ナビゲーションは画面下部

### Desktop

- メニューの管理・編集を重視
- 必要に応じて2カラム
- ナビゲーションはヘッダーまたはサイドバー
