## 1. プロジェクト概要

PCでトレーニングメニューを作成し、スマートフォンで手軽に記録できるライフログを含めたトレーニング管理アプリを開発する。
"ゆるく継続" を目指し、毎日記録しなくても、トレーニングを行うことに意味があるように管理するアプリを作成する。

v1ではトレーニング実績は実施有無のみを記録する。実施セット数、回数、重量などの詳細記録は将来対応とする。

## 2. 背景・目的

### 背景

現在、管理アプリとしては複数存在するため、自分に合ったアプリを探すのが億劫になったため、下記の内容に沿った自分好みのアプリを作成する。

- ゆるく継続できる自分好みにカスタマイズできるアプリが欲しい
- 自分に必要な機能だけ欲しい
- Notionと組み合わせて管理したい

### 目的

- 筋トレを継続しやすくする
- 入力を簡単にする
- 振り返りやすくする

## 3. ターゲットユーザー

### メイン

- 自分

## 4. コンセプト

"ゆるく継続" をコンセプトに続かなかった日があっても、気軽に再開できるように簡単操作で記録できる管理アプリ

## 5. スコープ

### 今回作る
- トレーニング記録
- メニュー管理
- 食事
- 睡眠
- ストレッチ
- 継続日数

### 作らない

- AI分析

## 6. 機能要件

| 機能 | 概要 | 優先度 |
|---|---|---|
| ダッシュボード | 今日のメニュー表示 | Must |
| トレーニング記録 | 実施したメニューの完了状態を記録 | Must |
| メニュー管理 | 作成・編集 | Must |
| 食事記録 | 簡易入力 | Must |
| 睡眠記録 | 時間を記録 | Must |
| ストレッチ | 実施記録 | Must |
| 継続日数 | 月間トレーニング回数 | Should |
| グラフ | 推移表示 | Could |

## 9. データ管理

### Workout Menu

トレーニングおよびストレッチのメニュー、予定セット数、予定回数、実施曜日を管理する。

### Daily Record

日ごとのトレーニング・ストレッチの実施状況、睡眠、食事、メモを管理する。

v1では、実際に行ったセット数、回数、重量は記録しない。

## 12. 設計方針

- PCとスマホで役割を分ける
- PCでは計画・管理を重視する
- スマホでは記録を最優先とする
- 操作回数をできるだけ少なくする
- 毎日使っても疲れないシンプルなUIを目指す
- Github Pages 経由での公開になるためセキュリティ面も問題ない設計にする

## 13. MVP

初回リリースでは以下を実装する。

- 曜日に応じた今日のメニュー表示
- トレーニング・ストレッチの実施有無の記録
- トレーニング・ストレッチメニューの作成・編集
- 食事記録
- 睡眠記録
- 月間トレーニング回数の表示
- 過去の記録の閲覧

実施セット数、実施回数、重量などの詳細なトレーニング実績は将来対応とする。
